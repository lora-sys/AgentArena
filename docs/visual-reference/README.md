# Visual reference index

This directory separates current Vite baselines from historical Next.js design evidence.

## Current

`current/` contains the latest reviewed desktop and mobile captures for the four supported experiences: landing, live battle, replay/result, battle archive, and Agent Passport. These images are visual QA references, not generated build inputs.

## Legacy

`legacy/` preserves the original exploration boards and removed Next.js page captures. They document design intent and migration history, but they are not implementation specifications.
