# Adversarial Review — v0.5.2 Visual Baseline (#45)

日期：2026-07-25  
范围：Live AI Degraded、运行模式切换、13 个视觉基线与三段动画证据。

## 已修复

### [HIGH] 降级模式只切换徽标，没有页面级证据不足状态

- 影响：StepFun 失败时仍会显示固定 fixture 的竞技场内容，可能被误读为本次实时输入的结果。
- 修复：`BattleWorkspace` 在 `demo_fallback` 下独占渲染 `LiveAiDegraded`，同时保留明确的模式徽标和返回已验证演示路径。

### [HIGH] 降级审计文案无条件声称攻击、防守和事件已记录

- 影响：运行可能在第一个事件前失败，文案会制造不存在的证据。
- 修复：改为“界面已安全降级／运行模式已明确标识／已验证演示可随时返回”，只陈述页面能够证明的事实。

### [MEDIUM] 倒计时到零后计时器仍持续唤醒

- 影响：生产路径通常会立刻导航，但测试替身或导航失败时会保留无效 interval。
- 修复：倒计时 interval 在归零分支主动清理，暂停和卸载也会清理。

## 未发现阻塞项

- 10 秒倒计时支持悬停、焦点与显式按钮暂停，CTA 可立即返回黄金剧情。
- `demo_fallback` 不展示冠军、分数、作品版本或固定 fixture 的证据内容。
- 13 张截图覆盖验收矩阵，Fatal、Champion、Degraded 均有动态证据。
- 新增可见字符串均经 `zh.ts`，样式未引入裸色值，组件未触碰 engine、contracts、数据库或 Secret。
