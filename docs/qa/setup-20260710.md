## What was set up

### 1. Vitest coverage tooling

**`vitest.config.ts`** — Extended with `@vitest/coverage-v8` provider.

- Provider: `v8` (faster than c8, uses Node's built-in coverage)
- Reporters: `text`, `html`, `lcov`, `json-summary`
- Output: `./coverage/`
- Per-file floor: 40% lines / statements / functions / branches (docs/test-guidelines.md §2)
- Coverage `include` scoped to `lib/`, `arena/`, `agents/` — storybook stories and demo data fixtures excluded (they are validated via agent-browser visual review per §3.5, not line coverage)

**Version pinning**: `@vitest/coverage-v8` pinned to `^2.1.9` to match `vitest@2.1.9`. The 4.x line is built against vitest 3+ and crashes with `BaseCoverageProvider` export mismatch.

**Sprint-0 thresholds are intentionally the global floor only.** Per-directory targets (engine 80, schemas 95, ui-kit 60) are tracked as coverage-debt tickets and enforced once each directory clears them. This keeps the gate green today and ratchets up over time.

### 2. Playwright E2E infrastructure

**`playwright.config.ts`** — Full config:

- **Browsers**: Chromium + WebKit (Firefox deferred to P1 per §3.4)
- **Viewports**: 1440x900 (desktop) + 390x844 (mobile, iPhone 14 Pro profile)
- **Base URL**: `http://localhost:3000` (overridable via `PLAYWRIGHT_BASE_URL`)
- **Retries**: 2 in CI, 0 locally
- **Reporter**: `list` locally; `github` + `junit` + `list` in CI; JUnit XML to `coverage/e2e/junit.xml`
- **Artifacts**: traces on first retry, screenshots on failure, video retained on failure
- **webServer**: `pnpm dev` auto-started locally; in CI the build job starts the server

**4 projects** = full matrix:
1. `chromium-desktop` — 1440x900
2. `chromium-mobile` — 390x844, touch enabled
3. `webkit-desktop` — 1440x900
4. `webkit-mobile` — 390x844, touch enabled

Every journey runs on every project without per-spec duplication.

### 5. CI integration

**`.github/workflows/ci.yml`** — New `e2e` job:

- Runs after `typecheck`, `lint`, `test`, `build` (serial dependency)
- Installs Playwright browsers with `--with-deps` (libicu, libflite for WebKit)
- Builds the app first, then runs `pnpm e2e` with `CI=true`
- Uploads `playwright-report/` and `coverage/e2e/` as artifacts
- JUnit XML in `coverage/e2e/junit.xml` for test reporting

The existing `test` job now uses `pnpm test:coverage` directly (changed from `--coverage` flag) so the script is the single source of truth.

## How to run locally

```bash
# Install everything
pnpm install

# One-time: install Playwright browsers
pnpm e2e:install

# Unit + integration tests
pnpm test                    # 115 tests, ~3s
pnpm test:watch              # watch mode
pnpm test:coverage           # + coverage report at coverage/index.html

# E2E
pnpm e2e                     # all 4 projects (chromium + webkit × desktop + mobile)
pnpm e2e -- --project=chromium-desktop  # single project
pnpm e2e:ui                  # interactive mode
```

To debug a failing journey:

```bash
pnpm e2e -- --project=chromium-desktop --debug
```

The HTML report lives at `playwright-report/index.html` after a run.
