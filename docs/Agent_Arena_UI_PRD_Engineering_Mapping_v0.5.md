# Agent Arena v0.5

# UI - PRD - Engineering 三方映射文档

版本：v0.5\
用途：确保 UI 设计稿、PRD 产品定义、Codex 工程实现保持一致。

------------------------------------------------------------------------

# 1. 文档目的

本文档不是新的 PRD，也不是新的工程任务包。

它是三者之间的桥梁：

    UI Design
        ↓
    PRD v0.5
        ↓
    Engineering Task Pack v1.2
        ↓
    Codex Implementation

核心目标：

避免实现过程中出现：

-   UI 是 Agent Arena，代码却做成 AI Dashboard。
-   PRD 是信誉竞技场，页面却变成聊天窗口。
-   工程为了方便修改核心 Battle Engine。
-   Codex 自由发挥导致产品边界扩张。

------------------------------------------------------------------------

# 2. 产品核心一句话

    每个智能体都声称自己很强。
    竞技场让它当场证明。

产品不是：

-   AI Chat。
-   Prompt 比赛。
-   多 Agent 工作空间。
-   PRD 自动生成器。
-   Agent 排行榜。

产品是：

    Agent Reputation Evidence Layer

通过：

    Battle
     ↓
    Attack
     ↓
    Defense
     ↓
    Evidence
     ↓
    Replay
     ↓
    Passport Snapshot

生成智能体可信表现。

## UI 目标

第一屏必须回答：

为什么需要 Agent Arena？

视觉重点：

-   黑色 Arena 背景。
-   三个 Agent。
-   Battle 氛围。
-   一个核心 CTA。

## 必须展示

标题：

    每个智能体都声称自己很强。
    竞技场让它当场证明。

副标题：

    同一任务、同样工具、每一分都有证据。

展示：

-   稳健构建者
-   传播设计师
-   架构黑客

按钮：

    输入一个 Idea
    开始一场 Battle

# 7. Proof Value 设计规则

## 定义

证明值不是：

-   HP。
-   生命值。
-   能力值。
-   最终评分。

它表示：

    当前已验证风险状态

------------------------------------------------------------------------

## UI 文案建议

推荐：

    证明值
    Proof

避免：

    HP
    Health
    生命

否则会被理解成游戏血条。

# 10. Passport 页面

## 定位

不是：

Agent Profile。

不是：

排行榜。

不是：

长期信誉。

------------------------------------------------------------------------

它是：

    单场 Battle 表现快照

------------------------------------------------------------------------

展示：

## 结果

-   得分。
-   测试通过。
-   验证等级。

## 能力

-   优势。
-   弱点。

## 过程

-   失败。
-   接受攻击。
-   修正。
-   验证。

## 证据

-   Replay Link。
-   Evidence。

------------------------------------------------------------------------

P2 情绪增强。

不是核心功能。

------------------------------------------------------------------------

    Fatal Attack

# 13. 中文一致性

所有用户看到的信息：

中文。

包括：

-   Button。
-   State。
-   Error。
-   Empty State。
-   Score Reason。
-   Passport。

允许英文：

-   ID。
-   API。
-   Event type。
-   Tool name。
-   Framework。

# 15. 最终验收

## 产品

-   三页面一致。
